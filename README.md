# Simon-says
Simon Says (JavaScript)

Простая браузерная игра по мотивам классической игры Simon Says.
Игрок должен запоминать последовательность подсвеченных клавиш и повторять её с клавиатуры или мышью.

📌 Описание проекта

Игра генерирует случайную последовательность символов, подсвечивая клавиши на виртуальной клавиатуре.
Задача игрока — правильно воспроизвести эту последовательность.

С каждым раундом сложность увеличивается (последовательность становится длиннее).

🎲 Случайная генерация последовательности

с клавиатуры

🧠 Архитектура

Проект использует замыкания (closures) для управления состоянием:

1. Управление раундами
roundManager

хранит текущий раунд

увеличивает раунд

сбрасывает значение

2. Состояние игры
gameState

start() — игра активна

stop() — игра остановлена

getState() — текущее состояние

3. Счётчик ввода
counterState

отслеживает текущий ввод игрока

сравнивает с последовательностью

🎯 Основная логика
Подсветка элементов
highlightRandomElement()

выбирает случайную клавишу

добавляет класс highlighted

Генерация последовательности
startHighlighting(maxCount, callback)

генерирует последовательность

сохраняет её в highlightedDivs

Проверка ввода
С клавиатуры:
checkKeys(pressedKey)
С мыши:
checkClikedKey(clickedKey)
Повтор последовательности

Новый раунд

Сброс игры
